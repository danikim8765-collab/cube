# 큐브 코치 🧊

폰과 패드에서 쓰는 **3×3 루빅스 큐브 멘토 웹앱**이에요. 완전 초보도 옆에 코치가 있는 것처럼 처음부터 끝까지 맞출 수 있게 한 단계씩 대화로 안내해요.

## 코치와 함께하는 흐름

1. **지금 큐브 입력**: 6면 × 9칸을 탭으로 칠해요. 면마다 잡는 방법이 적혀 있고, 칸 둘레의 색 막대가 옆 센터 색을 알려줘요. 다 맞춘 큐브가 있으면 앱이 **섞는 순서**를 알려줄 수도 있어요.
2. **상태 설명**: 7단계 중 어디까지 돼 있는지, 지금 할 단계가 무엇인지 쉽게 설명해요.
3. **잡는 방법**: "노랑 센터가 위, 빨강 센터가 앞"처럼 어느 센터를 위·앞으로 둘지 알려줘요. 방향이 바뀔 때는 따로 강조해요.
4. **한 수씩 따라하기**: 3D 큐브가 먼저 돌아가고 "오른쪽 줄을 위로" 같은 한국어 설명과 화살표 그림이 함께 나와요. 이전/다음/처음, 자동 재생, 속도 조절, 옮길 조각 강조를 할 수 있어요.
5. **결과 확인**: 예상 결과를 미리 채운 입력 화면에서 실제 큐브와 다른 칸만 고치면 돼요.
6. **실수 진단과 복구**: 결과가 다르면 흔한 실수를 시뮬레이션으로 찾아내요. 한 수를 반대로 돌린 경우, 빠뜨린 경우, 두 번 돌린 경우, 순서가 바뀐 경우, 반복 횟수가 틀린 경우, 윗층 대신 큐브 전체를 돌린 경우, **잘못된 방향으로 잡은 경우**를 찾을 수 있어요. 그러면 실수 전으로 **되돌리는 수순**을 같이 보여주거나, 지금 상태에서 새로 계획을 세워요. 입력 실수(면을 돌려서 입력, 두 면이 뒤바뀜, 몇 칸 오타)도 따로 짚어줘요.

## 풀이 순서 (초보자 방법)

| 단계 | 이름 | 공식 |
|---|---|---|
| 1 | 흰 십자 | 조각마다 계산된 수순 (흰색 위) |
| 2 | 흰 코너 | `R U R' U'` 반복 (흰색 아래) |
| 3 | 2층 | `U R U' R' U' F' U F` / `U' L' U L U F U' F'` |
| 4 | 노란 십자 | `F R U R' U' F'` |
| 5 | 노란 가장자리 맞추기 | `R U R' U R U2 R' U` |
| 6 | 노란 코너 자리 | `U R U' L' U R' U' L` |
| 7 | 코너 비틀기 | `R' D' R D` |

앱은 입력된 실제 상태로 위 방법을 그대로 시뮬레이션해서 **그 큐브에 꼭 맞는** 잡는 방향과 수순을 만들어요. 무작위 섞기 수천 개로 테스트했어요.

## 학습 기록 (이어서 하기)

- 진행 중인 단계와 수순, 몇 번째 수까지 했는지 자동 저장돼요. 다시 열면 **이어서 하기**로 바로 돌아가요.
- 단계마다 별을 모아요: ★ 한 번 해봄 · ★★ 3번 하거나 혼자 성공 · ★★★ 혼자서도 여러 번 성공.
- ★★ 단계는 **혼자 해보기**를 할 수 있어요. 막히면 힌트를 받고, 결과를 입력하면 확인해 줘요.
- 기록은 기기의 브라우저(localStorage)에 저장돼요.

## 더 배우기 · 다른 방법

초보법을 익히면 단계적으로 열려요. 잠긴 내용도 미리 엿볼 수 있어요.

- **항상**: 기호 완전 정복 (r, M, x y z), 공식 연습장 (아무 공식이나 3D로)
- **첫 완주 후**: 초보법 업그레이드, 4-Look 마지막 층 (2-Look OLL 7개 + PLL)
- **7단계 모두 ★★ 이후**: F2L 입문, 세계의 풀이법 지도 (CFOP · Roux · ZZ · Petrus)

공식을 누르면 그 공식이 필요한 상황을 만든 다음 푸는 모습을 보여줘요.

## 실행

빌드가 필요 없는 정적 사이트예요 (외부 라이브러리 없이 CSS 3D로 그려요).

```bash
npm start          # = python3 -m http.server 8080 → http://localhost:8080
npm test           # 풀이기 1000회 + 실수 진단 테스트
npm run build:single   # 모든 파일을 한 HTML로 묶기 (dist/)
```

**폰/패드에서 쓰기**: GitHub 저장소 Settings → Pages → *Deploy from a branch*에서 `main` / `/ (root)`를 고르면 `https://<아이디>.github.io/cube/` 주소가 생겨요. 그 주소를 사파리/크롬에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 한 번 열면 오프라인에서도 동작해요.

> 표준 색 배치(흰↔노랑, 초록↔파랑, 빨강↔주황, 흰 위·초록 앞일 때 빨강이 오른쪽) 큐브를 기준으로 해요.

## 구조

| 파일 | 역할 |
|---|---|
| `js/cube.js` | 54칸 상태, 회전(3D 좌표로 생성), 잡는 방향 24가지, 유효성 검사(패리티 포함) |
| `js/solver.js` | 7단계 판정과 단계별 계획 (흰 십자 BFS, 코너/2층 규칙, 노란 층 공식 탐색) |
| `js/diagnose.js` | 결과 비교, 실수 변형 시뮬레이션, 복구 수순 |
| `js/content.js` | 한국어 설명, 이동 아이콘, 단계 소개, 더 배우기 |
| `js/view3d.js` | CSS 3D 큐브 렌더링과 층 회전 애니메이션 |
| `js/input.js` | 탭으로 색 입력 |
| `js/store.js` | 학습 기록 저장 |
| `js/app.js` | 코치 대화와 화면 흐름 |
